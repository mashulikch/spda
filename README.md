# Лента мемов

Стартовый проект практики модуля «Фронтенд». За две пары из него получится лента мемов с лайками, которая берёт данные с сервера и живёт в интернете по вашей ссылке.

**Браузер — Chrome.** Сервер узнаёт вас по cookie с другого сайта, а Safari и браузеры на iPhone такие cookie могут не сохранить — тогда лайки не запомнятся.

## Подготовка

Дома после пары 1:

1. Аккаунт на [GitHub](https://github.com).
2. [Node.js](https://nodejs.org) — LTS-версия.
3. [Git](https://git-scm.com). На macOS проще всего `xcode-select --install`. Проверка: `git --version`.

В начале пары 2:

4. Вверху этой страницы: **Use this template → Create a new repository**. Отметьте **Include all branches**: в ветках лежат контрольные точки. Репозиторий оставьте публичным, иначе GitHub Pages не заработает.
5. Склонируйте **свой** репозиторий и проверьте окружение:
   ```bash
   git clone <ссылка на ваш репозиторий>
   cd <имя вашего репозитория>
   npm install
   npm run check
   ```

Три ✅ — вы готовы. Сервер пока может не отвечать (⚠️) — он понадобится только на паре 3.

Не получилось — не страшно: на паре садитесь к соседу и работайте вдвоём, а дома повторите по этой инструкции.

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | Запускает проект на `http://localhost:5173`; страница обновляется сама при сохранении файлов |
| `npm run build` | Собирает сайт в папку `dist/` |
| `npm run check` | Проверяет, что всё установлено |

## Шаги

| Шаг | Файл | Что сделать |
|---|---|---|
| ① | `components/MemeCard.jsx` | Карточка: картинка, подпись, лайки |
| ② | `components/Feed.jsx` | Лента из всех мемов |
| ③ | `components/LikeButton.jsx` | Лайк ставится и снимается |
| ★ | — | «Мемов пока нет»; сортировка по лайкам — `<select>` с `onChange` и состоянием, сортируйте копию: `[...memes].sort(…)`; тёмная тема — по клику поставьте `document.documentElement.dataset.theme = 'dark'`, цвета переключатся сами |
| ④ | `components/Feed.jsx` | Лента приходит с сервера. В `fetch` — опция `credentials: 'include'`; поле `liked` из ответа передайте в `LikeButton`. Как писать запросы к нашему серверу — подсказки в `src/api.js` |
| ⑤ | `components/Feed.jsx` | Загрузка, ошибка с кнопкой «Повторить», пустая лента. Проверьте: допишите к адресу в `fetch` `?delay=3000` или `?fail=1` |
| ★ | `components/LikeButton.jsx` | Лайк отправляется на сервер: `POST` ставит, `DELETE` снимает, с `credentials: 'include'`. После перезагрузки страницы лайк на месте |
| ★★ | `components/LikeButton.jsx` | Лайк ставится сразу, а при ошибке сервера откатывается |

### Отстали? Возьмите готовое начало шага

```bash
git checkout origin/step-3 -- src
```

Ветки: `step-2` … `step-5` — начало шагов ②–⑤, `solution` — готовы все шаги и лайки на сервере, но не сортировка и тёмная тема: их делаете сами. Код в `src` заменится, поэтому сначала закоммитьте своё: `git add -A && git commit -m "мой шаг"`.

## Деплой на GitHub Pages

1. В репозитории: **Settings → Pages → Source: GitHub Actions**. Репозиторий должен быть публичным.
2. `git add -A && git commit -m "Моя лента" && git push`. При первом push Git попросит войти в GitHub: обычно открывается браузер. Если терминал спрашивает пароль, пароль от аккаунта не подойдёт, нужен токен: GitHub → Settings → Developer settings → Personal access tokens.
3. Вкладка **Actions**: дождитесь зелёной галочки.
4. Ваша лента: `https://<ник>.github.io/<репозиторий>/`. Сдайте ссылку на [spda.voisvet.space/links](https://spda.voisvet.space/links).

Workflow уже лежит в `.github/workflows/deploy.yml`: каждый пуш в `main` — новая версия сайта.

## Если что-то сломалось

- **Белый экран** — откройте Console в DevTools: там файл и строка с ошибкой.
- **Поменяли `.env`** — перезапустите `npm run dev`.
- **Лайки не запоминаются после перезагрузки** — проверьте `credentials: 'include'` в каждом `fetch` и что лента открыта в Chrome.
- **Actions упал на первом запуске** — включите Pages (шаг 1 деплоя) и нажмите Re-run failed jobs.
- **`invalid reference` при `git checkout origin/step-…`** — при создании репозитория не отметили Include all branches. Спросите преподавателя: ветки можно подтянуть из шаблона.
